# 微信盒子代理商奖励分析平台

> 基于发货数据 + 微信后台激活数据，匹配每个代理商的拿货量与三类奖励达标情况。

## 🎯 功能概览

- **数据匹配**：通过 SN（设备号）将发货数据与每日激活数据关联
- **代理商解析**：自动从「备注」字段解析出区域 / 代理商 / 编号
- **三项奖励分析**：
  - 🎯 **落地技术服务费**：单月有效订单 ≥ 300 且月活用户 ≥ 20，奖励 200 元/台
  - 📈 **活跃技术服务费**：有效交易实收金额 × 0.16%，分两档封顶（10/50 元/月）
  - 🏆 **激活达标技术服务费**：月订单 ≥ 300 + 月活 ≥ 20 + 有效天数 ≥ 7 + 机构/非机构激活总量门槛
- **多维聚合**：按代理商、按区域、全局汇总
- **可视化看板**：3 项奖励达标分布、代理商排行、区域对比、奖励金额构成
- **导出 Excel**：含「按代理商/按区域/设备明细/全局汇总」四个 Sheet

## 🚀 快速开始

### 1. 准备环境

```bash
# 已使用托管 venv: /Users/fournine/.workbuddy/binaries/python/envs/wb-analysis
# 启动 Web 应用：
/Users/fournine/.workbuddy/binaries/python/envs/wb-analysis/bin/streamlit run app.py
```

打开浏览器访问 http://127.0.0.1:8501

### 2. 使用示例数据体验

点击侧边栏的「🧪 使用示例数据演示」按钮，程序会自动加载：
- `sample_data/发货数据-示例.csv`（24 个代理商，2615 台设备）
- `sample_data/激活数据-示例.csv`

### 3. 上传真实数据

- **发货数据**：包含「设备号 / SN」、「备注（含代理商信息）」等列
- **激活数据**：包含「设备 SN」、「有效交易订单」、「有效交易金额」、「月活用户」、「有效天数」等列

> 列名允许模糊匹配，详见 `core/data_loader.py` 中的关键字列表

### 4. 命令行使用

```bash
python cli.py \
  --shipping 发货数据.csv \
  --activation 激活数据.csv \
  --out 报告.xlsx
```

## 📊 政策参数可调整

侧边栏的「⚙️ 政策参数」面板允许在线调整：
- 落地最低订单数 / 月活用户数
- 活跃抽成比例
- 机构/非机构激活总数门槛
- 激活达标最低有效天数

## 🔍 数据格式建议

### 发货数据列

| 列名 | 说明 |
| --- | --- |
| 设备号 | 设备唯一标识，与激活数据匹配 |
| 备注 | 形如 "安徽+许朋 0001"（区域+代理+编号） |
| ICCID / IMEI | 可选 |

### 激活数据列（任一即可，关键字模糊匹配）

| 列名关键字 | 说明 |
| --- | --- |
| 设备SN / 设备号 / 终端号 | 设备唯一标识 |
| 有效交易订单 / 订单数 | 月度有效订单数 |
| 有效交易金额 / 实收金额 | 月度有效交易实收金额 |
| 月活用户 / 用户数 | 月活用户数 |
| 有效天数 / 活跃天数 | 有效天数 |
| 激活日期 / 首活日期 | 首次激活时间 |
| 采购时间 / 发货时间 | 设备采购时间（用于叠加费判定） |
| 是否机构 / 机构 | 标记机构/非机构 |

## ⚠️ 注意事项

1. **激活达标奖励**需要先满足「机构累计激活 ≥ 20,000 台 或 非机构累计激活 ≥ 10,000 台」总量门槛
2. **叠加技术服务费**需要同时满足：2026-06-30 前采购 + 当月活跃费达到 200 元
3. 如果激活数据是「每日快照」型（同 SN 多行），选「📸 取最新一天」；如果是「每日增量」型（同 SN 多行），选「➕ 全部行累加」

## 📦 输出文件

点击「📥 下载完整分析结果（Excel）」即可下载：
- **Sheet 1：按代理商** — 每个代理商的拿货、激活、三项奖励达标数、奖励金额
- **Sheet 2：按区域** — 各区域汇总
- **Sheet 3：设备明细** — 每台设备的奖励计算详情
- **Sheet 4：全局汇总** — 总数与金额合计
